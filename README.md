# brynwhyman.com

A homepage listing projects. Plain HTML/CSS/JS, no build step.

- **Add a project:** edit `projects.js` (fields are documented at the top) and put its screenshot in `images/`.
- **Edit the intro line:** it's the `<h1>` in `index.html`.
- **Preview locally:** `python3 -m http.server` then open http://localhost:8000.
- **Host:** works as-is on GitHub Pages (Settings → Pages → deploy from branch).

Font: Archivo (SIL Open Font License, see `fonts/`).
