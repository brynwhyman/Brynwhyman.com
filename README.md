# brynwhyman.com

A homepage listing fun projects. Plain HTML/CSS/JS, no build step.

- **Add a project:** edit `projects.js` (fields are documented at the top). Put screenshots in `assets/`.
- **Preview locally:** `python3 -m http.server` then open http://localhost:8000.
- **Host:** works as-is on GitHub Pages (Settings → Pages → deploy from branch).
